## 💻 Local Development Setup

### Prerequisites
- Node.js (v18.x or higher, tested on Node v24)
- npm (v9.x or higher)

### Steps to Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Nishita-2009/Nishita_Portfolio.git

# 2. Navigate to the project directory
cd Nishita_Portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📄 Resume PDF Setup

The official resume PDF is connected at:
```
public/resume.pdf
```
When users click **View Resume** in the navigation bar, hero section, or contact area, the browser automatically opens `/resume.pdf` in a new tab for seamless reading and reviewing.

Whenever you update your resume:
1. Export your latest resume as a PDF file named `resume.pdf`.
2. Replace `public/resume.pdf` with the new file.
3. Commit and push the changes to GitHub.

## 🚢 Deployment Instructions

### Deploy to Netlify (Recommended)
1. Push this repository to GitHub: `https://github.com/Nishita-2009/Nishita_Portfolio`
2. Log in to [Netlify](https://www.netlify.com/).
3. Click **Add new site** > **Import an existing project** > **GitHub**.
4. Select the `Nishita_Portfolio` repository.
5. Set the build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
6. Click **Deploy site**.

### Deploy to Vercel
1. Log in to [Vercel](https://vercel.com/).
2. Click **Add New...** > **Project**.
3. Import `Nishita_Portfolio` from GitHub.
4. Framework Preset: **Vite**.
5. Build command: `npm run build` | Output directory: `dist`.
6. Click **Deploy**.
